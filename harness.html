The noise floor

Run the identical model twice over the identical items. Any disagreement is noise, by construction — there is no model change to explain it. That number is the floor below which no regression can be distinguished from chance.

Why this is the measurement that matters

Every regression detector has a threshold. Set it below the noise floor and it fires constantly on nothing; set it above and real regressions pass through unnoticed. Almost nobody measures the floor, so the threshold is chosen by intuition.

Ground truth here is free. The model did not change between passes, so every flipped item is a false signal with no labelling and no judgment required — the same construction that makes a control group work.

A benchmark whose two identical passes disagree on 8% of items cannot resolve a 3% regression. That is arithmetic, not opinion.
